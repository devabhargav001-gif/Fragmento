
# ✦ Fragmento

**Fragmento** is a minimalist thought organizer that helps you organize scattered thoughts into meaningful categories.

Whether it's a random idea, a task, a question, or a quick note, Fragmento provides a clean and distraction-free space to capture and structure your thoughts.

---

## ✨ Features

- 📝 Capture thoughts instantly
- 📂 Organize thoughts into categories
- 🌙 Dark & Light Theme
- 📊 Live Character Counter
- 🎨 Clean & Minimal UI
- 📱 Responsive Design
- 🚀 AI-ready architecture for future updates

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript
